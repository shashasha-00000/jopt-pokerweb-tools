# JOPT Entry Confirmation Kiosk

固定平板で非NLHトーナメントへのエントリー確認を受け付け、確認時刻をGoogle Sheetsへ記録するApps Script Web Appです。

## 役割

- 平板側はGoogleアカウントへログインせず、Web AppのURLだけを開きます。
- 確認ボタンを押すと、サーバーの日本時間・デバイスID・結果・記録ID・APPバージョンを `確認ログ` シートへ保存します。
- 保存成功後に確認画面と成功音を出します。保存失敗時は成功扱いにしません。

## 初期設定

1. ログ保存用Google Sheetを作成し、タブ名を `確認ログ` にします。
2. `Code.gs` の `spreadsheetId` を対象Spreadsheet IDに置き換えます。
3. Apps Scriptプロジェクトへ `Code.gs`、`Index.html`、`appsscript.json` を配置します。
4. `verifySetup()` を実行し、SpreadsheetとScriptのタイムゾーンが `Asia/Tokyo` であることを確認します。
5. Web Appを「デプロイするユーザーとして実行」「全員（匿名ユーザーを含む）」でデプロイします。
6. Google未ログインのブラウザでWeb Appを開き、確認ボタンを1回押して `確認ログ` への追加を確認します。

## 運用

- 画面右上のボタンで音声をON/OFFできます。設定は端末のブラウザに保存されます。
- 端末自体が消音または音量0の場合、Web Appから音を強制再生できません。
- デバイスIDの初期値は `受付PAD-01` です。端末を増やす場合はデプロイ分離または設定方法の追加を検討します。
- Web App URLを知る人は確認操作を実行できるため、URLを不必要に公開しないでください。

## 顧客向け文面

画面内の顧客向け文面は、ユーザーから提示された既存ページの文面をそのまま使用しています。変更する場合は正式原文の確認が必要です。
