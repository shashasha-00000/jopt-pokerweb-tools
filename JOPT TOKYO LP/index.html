About JOPT

亚洲顶级扑克盛会

来自不同国家和地区的玩家齐聚 JOPT，在比赛中全情投入，也为彼此的表现喝彩。这里汇聚 Main Event、Side Event 及多种赛制，带来 JOPT 独有的现场扑克体验。

第一次参加，也能一步步找到适合自己的比赛

JOPT 在日本多个城市举办现场扑克赛事。每一站会根据当期赛程安排不同价位和形式的比赛，包括 Main Event、Side Event、高额赛事、团体赛及多种非 NLH 玩法。中国版指南将报名、座位确认和奖金领取流程集中整理，方便出发前查看。

FAQ

常见问题

常用指南入口

Game ID 与报名

第一次参加 JOPT，需要先做什么？
请先查看“第一次参加 JOPT？”中的完整参赛流程，从 STEP 01 注册 Game ID 开始，依次确认报名、入座和奖金领取方法。
Game ID 可以到达会场后再注册吗？
可以到达会场后再注册，现场工作人员会全程协助您完成注册。
中国大陆怎么下载 Game ID？
请使用日本区 App Store，并开启 VPN 下载。中国区账号无法下载。
没有日本手机号，可以注册 Game ID 吗？
可以。注册 Game ID 时，请将区号选择为日本（+81），电话号码填写本国号码即可。
没有日本地址，可以注册 Game ID 吗？
可以。注册时请将国家/地区选择为“日本”。没有日本地址的玩家，可在地址栏填写任意内容。
Game ID 的姓名应该怎么填写？
必须使用英文填写，不支持汉字或其他输入方式。
Game ID 无法注册或不会注册怎么办？
可以前往一楼大厅右侧的国际服务窗口，请认准 International Counter 指示牌。现场工作人员可以协助确认。
参加比赛需要提前报名吗？
除少数预约制比赛外，其他比赛均为现场报名。如需了解预约制比赛详情，可以咨询官方微信客服。
主赛（Main Event）可以直接买入吗？
Main Event 目前没有传统意义上的现场直接买入（DBI）。短期赴日、未持有门票的海外玩家，可在会场办理"特别赞助"手续：出示护照核实资格、确认并签署《赞助同意书》、支付赞助金额后，将受邀获得本赛事的 Main Event 参赛资格，再凭资格前往主赛报名处完成报名。具体赞助金额、支付方式以赛事现场说明为准；资格仅限本人使用，不可转让、出借或退款。🛂海外玩家特别赞助参赛指南即将上线
报名窗口怎么找？
先确认要参加的赛事名称，再查看报名窗口指南和现场指示牌，前往对应窗口排队。
赛场可以用人民币兑换日元吗？
赛场不提供人民币兑换日元服务。如需兑换日元，请前往银行或正规的外币兑换机构办理。
报名支持哪些支付方式？
现场支持微信、支付宝、银联、Visa、Mastercard 等支付方式。带有银联标志的中国银行卡可以使用。使用现金时仅支持日元，不接受人民币现金。

比赛与观赛

不会日语也可以参加比赛吗？
可以。JOPT 比赛的官方语言为日语和英语。如需中文协助，请咨询现场工作人员。
在哪里查看比赛规则？
比赛采用 JOPT Official Rule，并依据 TDA 2024 规则进行。最终裁定以 JOPT House Rule 及现场赛事总监（TD）的决定为准。
查看 JOPT Official Rule →
查看 TDA 2024 中文版 →
没有参赛的朋友可以进入会场观赛吗？
可以，没有参赛的同行者也可以进入会场观赛。
未满18岁可以进入会场观赛吗？
可以，但有入场时间限制。未满16岁者在18:00后不可入场；16～17岁者在22:00后不可入场，即使有监护人陪同也不例外。已满18岁但仍在读高中的人员，22:00后也不可入场或继续停留。
会场内可以拍照或录像吗？
可以，但需要提前申请 Media Pass。申请方法请扫描下方二维码查看。

比赛期间可以暂时离开会场，之后再回来吗？
可以。但离席期间比赛仍会正常进行，轮到您支付盲注或前注时，将照常从您的筹码中扣除。

交通与到场

如何从机场到赛场？
从成田机场出发：乘坐京成 Skyliner 到日暮里站，换乘 JR 山手线到高田马场站。
从羽田机场出发：乘坐京急线到品川站，换乘 JR 山手线到高田马场站。
从高田马场站步行约 9 分钟即可到达会场。
日本的电车怎么乘坐？
车票、IC 卡、进出站及换乘方法，请查看中文指南。
查看日本电车搭乘中文指南 →
会场可以寄存行李吗？
可以在报名处寄存行李箱。寄存服务仅限行李箱，详情请咨询现场工作人员。
会场有停车场吗？
会场不提供停车场。如驾车前来，请使用附近的公共停车场。

会场内

拿到座位票后去哪里？
先确认票面是否有桌号和座位号。有座位号时根据 Floor Map 入座；没有座位号时，前往票面盖章字母对应的柜台。
会场可以随便抽烟吗？
会场及周边区域均不可随意吸烟。会场内设有指定吸烟区，具体位置请参考 Floor Map。
会场有 Wi-Fi 吗？
有，现场有可供玩家使用的免费 Wi-Fi。
会场有可以给手机充电的地方吗？
可以，会场内设有充电宝租借点，具体位置请参考 Floor Map。
会场内可以携带食物和饮料吗？
不可以，禁止携带外购食品和饮料进入会场。
在会场遗失物品怎么办？
请前往报名前台咨询现场工作人员。
会场有中文工作人员吗？
有，如需中文协助，请咨询现场工作人员。
在会场身体不适或遇到紧急情况怎么办？
请立即联系现场工作人员。如有需要，工作人员可以协助呼叫救护车。
遇到地震或火灾等紧急情况怎么办？
请保持冷静，立即停止比赛，并按照现场广播及工作人员的指示有序撤离。请勿擅自行动或使用电梯。地震发生时请先保护头部，待摇晃减弱后再按指示避难。
饮料柜台在哪里？
下电梯后左转，沿路直走即可看到饮料柜台，可以使用 Drink Ticket 兑换饮料。
Drink Ticket 可以在哪里使用？
可以在会场饮料柜台以及网站介绍的合作餐厅使用。使用条件请以现场及店铺说明为准。
Sit & Go 在哪里报名？
Sit & Go 报名窗口和一般比赛不同，不在一楼。请前往 B2 层的 Sit & Go 报名窗口（A 柜台）。

奖金与领奖

领取奖金需要准备什么？
需要获奖者本人于当天前往选手契约柜台，并携带护照办理领取手续。
为什么我的 Pokerweb Coin 无法使用？
Pokerweb Coin需要通过本人验证才可以在APP中进行转账操作，本人验证根据情况可能会花费较长时间，不能保证次日可以立即使用。
USDT 什么时候转入个人钱包？
选择以USDT方式领取奖金的玩家，将统一在赛事结束后约3周内到账，具体详情查看随后的客服联络邮件。
